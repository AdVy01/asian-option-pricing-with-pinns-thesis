### (work in progress)
This is a supplemental code for a thesis Numerical Pricing of Arithmetic Asian Options Using Physics-Informed Neural Networks , written at FNSPE CTU in Prague

## This repo contains:
- PINNs applied on the 3D Asian option pricing PDE
- PINNS applied on the 2D reduced pricing PDE (reduced using the Večeř dimension reduction)
- Monte Carlo simulation
- Večeř dimension reduction
